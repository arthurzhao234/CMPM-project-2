Project Overview
2D Platformer Adventure is a side-scrolling platform game where the player controls a knight, collects coins, avoids enemies, and progresses through score-gated areas. The game focuses on movement timing, platform navigation, enemy avoidance, and simple progression systems.
Design Verbs
This project connects to two design verbs from the provided verb list:
●Bounce: The core gameplay is built around jumping between platforms, landing safely, and using vertical movement to navigate the level.
●Chase: Slime enemies create pressure by threatening the player and encouraging quick movement, dodging, and careful route planning.
